# 🧮 BMI Calculator (Python)

This is a simple Python project that calculates the Body Mass Index (BMI) based on user input and classifies the result into standard health categories.

## 📌 Features
- Takes user input (name, weight, height)
- Calculates BMI using the standard formula
- Provides health classification:
  - Underweight
  - Normal weight
  - Overweight
  - Obese categories

## 🧠 Formula Used
BMI is calculated using:

BMI = (weight in pounds × 703) / (height in inches × height in inches)

## 📊 BMI Classification
| BMI Range       | Category          |
|----------------|------------------|
| < 18.5         | Underweight      |
| 18.5 – 24.9    | Normal Weight    |
| 25 – 29.9      | Overweight       |
| 30 – 34.9      | Obese            |
| 35 – 39.9      | Severely Obese   |
| 40+            | Morbidly Obese   |
